# Iqbal's Meat & Deli · website demo

Premium NIHT-certified halaal butchery & deli (Benoni & Lenasia). Client demo by Pixel Code.

- `npm install` then `npm run dev` to work locally
- `npm run build` outputs a static site to `dist/` (relative paths, runs from any subfolder)

Edit business details & photos in `src/config/site.js`, products & prices in `src/data/products.js`,
the optional live AI chat hook in `src/config/ai.js`, and the payment placeholder in `src/lib/payments.js`.

3D assets: wooden cutting board model and studio HDRI by Poly Haven (CC0).
